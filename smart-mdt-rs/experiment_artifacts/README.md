# Historical experiment artifacts

The nested result folders contain small development and smoke-test artifacts.
They are retained for regression history only and are not publication or
thesis-freeze evidence. In particular, `smart_mdt_rs/` contains five synthetic
quick rows rather than the 46-dataset research benchmark.

The current benchmark, evaluation, checksum manifest, and freeze decision are
identified in `../docs/FINAL_FREEZE_REPORT.md`.
